# Collaborator logos

Drop official logo files here and the Research collaborations strip will show them
instead of the text names. No code changes needed.

Use these exact file names (SVG preferred, PNG also works):

| Organisation           | File name                                       |
| ---------------------- | ----------------------------------------------- |
| Defra                  | `defra.svg` or `defra.png`                      |
| Noise Consultants Ltd. | `noise-consultants.svg` or `.png`               |
| NASA                   | `nasa.svg` or `.png`                            |
| Noise Network Plus     | `noise-network-plus.svg` or `.png`              |
| Joby Aviation Ltd.     | `joby-aviation.svg` or `.png`                   |
| HEAD Acoustics GmbH    | `head-acoustics.svg` or `.png`                  |
| Dyson                  | `dyson.svg` or `.png`                           |
| Arcani                 | `arcani.svg` or `.png`                          |

Logos are shown in greyscale, up to 160 × 56 px. A version on a transparent
background works best. Check each organisation's brand guidelines, and get
permission where needed, before publishing their logo.
