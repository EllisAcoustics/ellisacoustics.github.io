# Fonts

`sourcerer-*.woff` are Latin subsets of **Sourcerer**, from Nico Verbruggen's ebook-fonts
collection (https://github.com/nicoverbruggen/ebook-fonts), a heavier take on Adobe's
Source Serif 4. Both are released under the SIL Open Font License 1.1
(https://openfontlicense.org). They are used for the home page title, the Net Zero
line and paper titles.
